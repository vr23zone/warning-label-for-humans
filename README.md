A Node 22 program (`main.ts`, standard library only) that writes one single-line safety warning label for human beings to `/output/entry.txt`:

> WARNING: Human contains 60% water, 40% unread messages, and 0% idea where the charger went.

Run it: `node main.ts` — it creates `/output` if needed and writes the line.
